# 발행용 영상

인스타그램 Graph API 는 파일을 올려받지 않고 **공개 URL 을 읽어간다**.
그래서 릴스로 낼 영상을 여기에 두고 `https://waffletrip.com/video/<파일명>` 을
발행 스크립트에 넘긴다. 인스타 서버가 로그인 없이 가져가므로 접근 제한을
걸면 안 된다.

- 파일명은 영문·숫자·하이픈만 쓴다. 한글 파일명은 URL 인코딩에서 사고가 난다.
- 발행이 끝난 영상은 지운다. 저장소가 무겁고, 사이트는 신문이지 영상 창고가 아니다.
- `.gitignore` 가 mp4 를 막고 있지 않은지 확인하고 커밋한다.
