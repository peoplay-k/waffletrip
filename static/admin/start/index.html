편집실 시작하기

편집실은 이미 만들어져 있습니다. 처음 한 번만 로그인 열쇠(토큰)를 만들면 됩니다. 5분 걸립니다.

  1. GitHub 에 로그인한 상태로 아래 버튼을 누릅니다

    열쇠 만드는 화면이 열립니다. 이름·기간·권한은 미리 채워 두었습니다.

    열쇠 만들기 화면 열기
    화면에서 이것만 확인하세요.
    · Resource owner: peoplay-k
    · Repository access: Only select repositories → waffletrip 하나만 고르기
    · Permissions → Contents: Read and write (비어 있으면 직접 고르기)
    · 다른 권한은 고르지 않습니다.

  2. 맨 아래 초록 버튼 Generate token 을 누릅니다

    github_pat_ 로 시작하는 긴 글자가 나옵니다. 옆의 복사 버튼으로 복사합니다.

    이 글자가 편집실 열쇠입니다. 카톡·채팅·메일에 붙여 넣지 마세요. 화면을 닫으면 다시 볼 수 없으니, 바로 3번으로 갑니다.

  3. 편집실을 열고 Sign In Using Access Token 을 누릅니다

    편집실 열기

    복사한 글자를 붙여 넣으면 로그인됩니다. 이 브라우저가 기억하므로 다음부터는 바로 열립니다.

    "Sign In with GitHub" 버튼은 쓰지 않습니다. 공용 컴퓨터에서는 다 쓰고 오른쪽 위 메뉴에서 로그아웃하세요.

  4. 기사 올리기 · 고치기

    새 기사: 왼쪽 기사 → 새로 만들기 → 상태를 발행대기로 두고 저장. 10분 안팎에 지면에 나갑니다.

    실린 기사 고치기: 목록 위 필터 발행됨 → 기사를 열어 고치고 저장. 상태는 발행됨 그대로. 10분 안팎에 지면이 바뀝니다.

열쇠는 90일 뒤 만료됩니다. 로그인이 풀리면 이 쪽에서 1번부터 다시 하면 됩니다. 1번 화면에 peoplay-k 가 안 보이거나 저장소가 안 보이면, 그 화면을 캡처해 보내 주세요(열쇠 글자는 보내지 마세요).
