전체 점검(`docs/AUDIT-2026-09-09.md`)에서 코드로 끝낼 수 있는 것은 전부 끝났다.
남은 넷은 **등록 신청·약관 동의·계정 로그인·결제** 때문에 대신 할 수 없는 것들이다.
각각 **지금까지 준비된 것**과 **사장님이 누를 것**을 나눠 적는다.

마지막 확인 2026-09-10.

## 13. 방문 통계(GA4) — 준비 끝. 측정 ID 한 줄만 넣으면 된다

**준비된 것 (실측 확인)**

`analytics.yaml` 의 `ga4` 에 값을 넣으면:

| | 값이 비었을 때(지금) | 값을 넣었을 때 |
|---|---|---|
| 전 페이지 | 외부 스크립트 0 | gtag 스크립트 자동 삽입 |
| 개인정보처리방침 | "분석 도구나 광고 추적기를 심지 않습니다" | "구글 애널리틱스 … **쿠키를 사용**합니다" 로 자동 교체 |

더미 ID(`G-TESTONLY123`)로 켜고 끄며 양쪽을 실제로 확인했다.
**방침 문구가 자동으로 따라오므로 페이지가 거짓말을 하게 될 일은 없다.**

**사장님이 할 것**

1. analytics.google.com → 속성 만들기 → 데이터 스트림에 `https://waffletrip.com`
2. 받은 측정 ID(`G-` 로 시작)를 `analytics.yaml` 의 `ga4:` 에 넣고 푸시
3. 끝. 배포되면 통계가 쌓이기 시작한다

**안 넣어도 되는 이유도 같이 적는다.** 구글 서치콘솔이 이미 붙어 있어
**검색어·노출수·클릭수·순위**는 지금도 보인다. GA4 가 더 주는 것은 사이트
안에서의 이동 경로와 체류 시간이다. 그게 필요 없으면 안 넣는 쪽이 낫다 —
쿠키가 생기고 방침 문구가 길어진다.

**쿠키 없는 절충안**: `analytics.yaml` 의 `cloudflare` 에 Web Analytics 토큰을
넣으면 쪽별 조회수와 유입 경로만 센다. 쿠키를 쓰지 않고, 방침 문구도 그에 맞게
자동으로 바뀐다. 무료다.

## 14. 편집실(/admin/) — 로그인 중개기만 띄우면 된다

사람이 브라우저에서 해설 기사를 쓰고 발행 대기로 넘기는 화면이다.
`https://waffletrip.com/admin/` 에 이미 떠 있고, 검색엔진은 막아두었다
(robots.txt `Disallow: /admin/` + `noindex`).

**준비된 것**

- 편집실 화면과 입력 항목 전부 (`static/admin/config.yml`)
- **지역 선택지 10곳** — 2026-09-10 에 일본·태국·대만이 빠져 있던 것을 고쳤다.
  앞으로 어긋나면 테스트가 잡는다.
- 로그인 중개기 코드 (`tools/oauth-worker.js`) — 붙여넣기만 하면 되게 돼 있다

**사장님이 할 것** (한 번만, 10분)

1. GitHub → Settings → Developer settings → OAuth Apps → New
   - Homepage URL `https://waffletrip.com/`
   - Callback URL `https://<워커주소>/callback` (2번에서 정해진다)
   - Client ID 와 Client Secret 을 받는다
2. Cloudflare → Workers → Create → `tools/oauth-worker.js` 내용을 붙여넣고 Deploy
3. Worker → Settings → Variables 에 **Secret 으로** 두 개
   - `GITHUB_CLIENT_ID`
   - `GITHUB_CLIENT_SECRET`
4. `static/admin/config.yml` 의 `base_url` 을 워커 주소로 바꾸고 푸시

**Client Secret 은 절대 저장소에 넣지 않는다.** Worker 환경변수에만 둔다.

## 11. 인터넷신문 등록 — 등록할지, 표현을 바꿀지

이 사이트는 '신문'·'기사'·'데스크' 라는 말을 쓴다. 「신문 등의 진흥에 관한 법률」은
인터넷신문을 시·도에 등록하도록 하고 있다. 두 갈래가 있고 **사장님이 정할 일**이다.

**갈래 A — 등록한다**

- 발행인·편집인 정보, 사업자 정보, 취재·편집 인력 요건이 붙는다
- 등록하면 정식 언론사가 된다. 언론중재법의 정정보도 절차도 따라온다
- 지금처럼 해설을 AI 가 쓰는 구조가 인력 요건과 맞는지는 **관할 시·도에 직접
  확인해야 한다.** 내가 판단할 수 있는 영역이 아니다

**갈래 B — 등록하지 않고 표현을 바꾼다**

- '신문' → '여행 정보 매체', '기사' → '글', '데스크' → '팀' 같은 정리
- 코드에서 바꿀 곳: `src/desks.py`(BRAND·데스크 이름), 각 템플릿 문구,
  `/about/`·`/ethics/` 페이지. **반나절이면 끝난다. 말씀만 주시면 한다**

**지금 상태에서 위험한 것은 없다.** 등록했다고 주장하는 문구는 어디에도 없고,
정정보도 절차는 `/ethics/` 에 자발적으로 적어두었다.

## 15. 유튜브 — 나레이션 비용 결정

**준비된 것**

- 대본·화면 자동 생성 (`tools/make_video.py`, `tools/make_shorts.py`)
- 홈에 걸리는 숏폼 자리 (`static/video/`)

**막힌 것**

- 나레이션 음성이 유료다
- 업로드는 사람이 한다 (채널 계정 필요)

**결정할 것**: 나레이션을 살 것인가. 안 산다면 **자막만 있는 무음 영상**으로
가는 방법도 있다 — 트렌드 음원을 얹는 포맷이라 오히려 그쪽이 맞을 수도 있다.
말씀 주시면 무음 자막 포맷으로 먼저 만들어 본다.
