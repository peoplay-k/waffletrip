# 영상 배경음

영상(쇼츠·주간 롱폼·오늘의 방송)에 까는 배경음을 여기서 고른다.

- `travel/` — 여행 쇼츠·주간 롱폼
- `ent/` — 연예 '오늘의 방송'
- 폴더에 곡이 없으면 이 폴더(`assets/music/`) 전체에서 고른다. 하나도 없으면 배경음 없이 나간다.

넣는 법: mp3(또는 m4a·wav)를 해당 폴더에 올린다. 파일 이름은 아무거나 괜찮다.
영상마다 곡과 곡 안의 시작 지점이 바뀌고, 크기는 자동으로 맞추며, 말할 때는 작아진다.

**유튜브에 올라가는 음악이다.** 상업 음원(가요·팝)은 저작권 신고(Content ID)로 수익이 막히거나
영상이 차단된다. 유튜브 오디오 보관함의 '저작자 표시 필요 없음' 곡이나 직접 산 라이선스 음원만 넣는다.
